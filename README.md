# Aniruddha Dutta — GitHub Pages personal site

Portfolio page

## Easy customizations

- Replace the `AD` circle in `index.html` with a headshot later if desired.
- Add Google Scholar and GitHub links when available.
- Update publication links/titles in the `#publications` section.
- Edit colors in the `:root` variables at the top of `styles.css`.

## Files

- `index.html` — site content
- `styles.css` — layout and visual design
- `script.js` — mobile menu and active navigation
- `assets/Aniruddha_Dutta_Resume.pdf` — downloadable resume
